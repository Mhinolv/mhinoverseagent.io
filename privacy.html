Hermes privacy policy

Last updated: 9 November 2026

Hermes is a personal assistant for one user, its owner, Mark Hinojosa. It has no other users.

Google data that Hermes uses

  • Gmail, read only (gmail.readonly): Hermes reads messages to answer the owner's questions. It cannot send, change or delete email.
  • Google Calendar (calendar): Hermes reads events and creates or changes events when the owner asks.

How the data is kept

  • The sign-in token is stored on the owner's private server, readable only by the assistant's own user account.
  • Hermes does not sell, share or give Google data to any third party, and it does not use it for advertising.
  • To answer a request, parts of the data go to the language model service that the owner uses for the assistant.
  • Hermes does not use Google data to train AI models.

Limited Use

Hermes's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Remove access

The owner can remove access at any time at myaccount.google.com/permissions.
